# Experiências narrativas — patch frontend

## Como aplicar
Na raiz do teu projecto (pasta com backend/ e frontend/):

```bash
unzip -o magistratura-experiencias-narrativas-front.zip
```

Ou copia manualmente:
- frontend/src/jornada/seed.js
- frontend/src/jornada/experiencias/ (pasta nova)
- frontend/src/views/CaminhadaView.vue
- frontend/src/views/ExperienciaJoaoView.vue

Reinicia o frontend (`npm run dev`).
